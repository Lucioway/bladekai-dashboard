# BLADE//KAI — Design Bible

Single-page design dashboard for **BLADE//KAI** (`BLADE改`) — a PvP-first arcade shooter with MMORPG depth, S4 League combat DNA, anime-cyberpunk aesthetic.

Static site. Deployed on Render.

- `index.html` — the full design bible (lore, world, competitive design, classes, equipment, movement, modes, factions, progression, art gallery)
- `assets/` — concept art (web-optimized)
